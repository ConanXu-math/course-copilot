# 同学 A：教材、讲解与练习 Demo

这三个 Skill 随项目提供，默认路径会根据每个人的项目位置计算：

| 页面按钮 | 维护文件 | 输出 |
| --- | --- | --- |
| 教材解析 | [SKILL.md](../skills/textbook-parse/SKILL.md) | 按页整理的正文、LaTeX、图片、目录和原页预览 |
| 讲解内容 | [SKILL.md](../skills/explain/SKILL.md) | 概念解释、关键推理、例子和学习资料 |
| 知识点出题 | [SKILL.md](../skills/quiz/SKILL.md) | 练习题、集中放置的答案解析，或按要求只提供题目 |

## 启动与演示

1. 在项目目录执行 npm install、npm run dev，打开终端显示的本机地址。
2. 导入自己的 PDF，打开工作区设置，连接已登录的 Coding Agent。
3. “接入 Skill”中这三个功能应显示“已配置”。如果个人设置以前保存过空路径或旧路径，重新填写当前项目相应的 SKILL.md 路径并保存。“生成课件”也已内置；思维导图、知识图谱和讲解视频仍待接入。
4. 选择页码和范围，再点击按钮发送要求。Agent 完成后，点击回答中的资料卡片，在左侧打开结果。

对话和学习资料中的独立公式提供“查看 LaTeX”和“复制代码”；行内公式点击后可查看并复制源码。公式只需输出一次，下载的 Markdown 也保留源码。教材解析按页保存定义、公式、例题等内容到 outputs/textbook-content，讲解与出题可继续复用。

可以用同一小节连续演示：

- 教材解析：“整理当前页的正文和公式，保留 PDF 页码，并附原页预览供我核对。”
- 讲解内容：“解释这里的核心概念和公式之间的关系，用一个简单例子展开，并保存成学习资料。”
- 知识点出题：“围绕刚才的知识点出 3 道由浅入深的题，先给题目，答案和解析集中放在最后。”

也可以要求“先不给答案”，然后提交自己的作答继续讨论。题数、难度和题型由要求决定，不需要额外设置页面。

## 教材读取程序

scripts/read-pages.mjs 位于教材解析 Skill 目录中，使用项目已经安装的 PDF.js 及其 Node 画布依赖。它读取真实 PDF，保存正文及目录到 source.json。使用 --images none 只读取文字，--images pages 增加原页预览，--images all 再导出内嵌图片；省略该参数保持原有 all 行为。Skill 按需要选择，避免每次阅读都渲染图片。

正常 npm install 会安装 PDF.js 的可选画布依赖；如果安装时跳过了可选依赖，需重新安装后才能生成原页预览。程序接收 --pdf、--start、--end、--out；本机 Node.js 路径和程序路径由课程服务随任务提供。讲解和出题也能按需使用同一个读取程序。

PDF 中的公式文字层不一定保留完整数学结构，因此 LaTeX 由 Agent 结合原页图像校对重建。扫描页的识别取决于实际 Agent 的图像读取能力；看不清的内容应标为待核对。矢量图和无法独立导出的图片仍保留在原页预览中，不能把原页截图称为单独提取的插图。

## 数据与实际范围

生成的 .md、JSON、图片都保存在当前课程 outputs 下，默认展示为带公式和图片的学习资料。教材解析 Demo 不自动覆盖原始 PDF 或写回左侧教材目录。

这些 Skill 不包含个人账号、固定服务地址或特定教材内容。换电脑时使用自己的 Agent 登录和个人课程文件夹。配图由所选 Agent 根据其实际可调用的 API 和工具自主完成，有文生图能力时优先使用，否则程序绘图。

修改 SKILL.md 后，下一次任务会读取新要求；修改教材读取程序后直接使用新的程序。三个 Skill 可分别维护，公共教学提示词和 Agent 连接代码继续共用。
