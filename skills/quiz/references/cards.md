# 卡片输出与交互

新练习默认使用本轮给定的结果 JSON 路径和 ID，写入：

```json
{
  "id": "本轮给定的 ID",
  "title": "知识点练习标题",
  "kind": "quiz",
  "questions": [
    {
      "id": "q1",
      "prompt": "完整题干，选择题的选项也写在这里。",
      "knowledgePoint": "本题知识点",
      "difficulty": "基础",
      "page": 22,
      "hints": ["概念方向", "关键关系", "下一步操作"],
      "answer": "参考结论",
      "explanation": "关键步骤、评价依据和易错原因"
    }
  ]
}
```

- questions 非空；每题 id 唯一，prompt 必填。其余字段按实际内容提供，页码为 PDF 页序且不可猜测；示例页码只是字段说明。
- 题干、提示、答案、解析均支持 Markdown 和 LaTeX，JSON 中反斜杠必须正确转义。图片引用本课程实际生成的 outputs 文件。
- 界面一次显示一题，提供题号切换、作答框、渐进提示、答案展开、教材页跳转和 Copilot 反馈。题干中不提前放答案，提示不重复题干或照抄整段解析。
- 用户要求“不给答案”时省略 answer 与 explanation，不把答案放进其他字段。不能承诺考试保密：本机资料中的参考答案仅在界面默认折叠。
- 默认不重复生成同内容的 Markdown 或 LaTeX 文件。旧 Markdown 练习仍能阅读；用户明确要求试卷、打印或导出时可生成 Markdown 资料。

## 作答与补练

点击反馈会将当前题目与学生作答发到对话。只评价该题并保留学生继续思考的空间；不重做整份题集，不透露其他题的答案，不写新的结果文件。反馈会随本机对话保存，卡片草稿在当前页面暂存。

要求变式时结合当前题和已有反馈，围绕首个关键错误设计一道有针对性的新题，并自行求解检查后保存为新的 quiz。无已有错误证据时，只做同知识点变式，不断言学生薄弱。提示和参考答案仍分别放置。
