# 知识点出题

每道题都应对应一个明确的知识点，并能区分学生是否理解，而不只是记住教材措辞。

1. 读取本轮教材、范围和要求，列出这次要练习的知识点。内容不足时使用本轮提供的教材读取工具。出题范围以教材和用户要求为准，额外先修知识要说明。
2. 遵循用户指定的题数、题型、难度和答案呈现方式。未指定时，以 3 道由浅入深的小练习起步，按内容选择概念辨析、计算、推导或应用，不强行涵盖所有题型。
3. 为每道题写清条件和任务。判断题要求说明理由；选择题的干扰项来自真实易错点，核对正确选项数量；计算题给出足够数据；开放题说明评价依据。生成的练习标为“根据教材编写”，不能称为教材原题。
4. 先独立求解，再检查题目。核对解是否存在、是否唯一、公式和数值是否正确，反例是否符合全部条件；发现问题先修题或答案再交付。难度由推理要求决定，不通过缺条件、绕口表达或堆计算制造困难。
5. 默认先展示完整题目区，再集中给出答案解析区，方便自测。每题标明对应知识点和参考 PDF 页码；解析包括结论、关键步骤、容易出错的原因。用户要求不提供答案时，只保存题目，等追问或作答后再揭示。
6. 学生提交作答后，按对应题目逐步反馈，区分概念错误、推理缺口与计算失误。优先指出已经做对的部分和需要修改的位置；题目本身有歧义时先修正题目。一次作答不代表已经全面掌握该知识点。

出题结果默认保存为 markdown 学习资料，同时在 outputs 保留 .md 正文；使用本轮给定的结果路径和 ID。公式使用 $...$ 或 $$...$$。图形题按本轮实际可用的配图能力生成，答案以数学关系和明确条件为准。
