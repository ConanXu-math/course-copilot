# 知识点出题

每道题对应明确的知识点，检验理解与应用。先判断本轮是出题、要提示、作答反馈还是补练，不把每次追问都变成新试卷。

1. 以教材、选定范围和用户要求为准，优先复用当前资料和已解析内容；缺内容或有疑点再读取原页。额外先修知识要说明，不扩展到无关章节。
2. 遵循指定的题数、题型、难度和答案方式。未指定时出 3 道由浅入深的小练习，按内容选择辨析、计算、推导或应用，不强行凑齐题型。只练薄弱点时，以实际作答或用户指定的困难为依据，不把一次失误当成全面不会。
3. 条件与任务明确：判断题要求理由；选择题核对正确选项数量，干扰项来自具体易错点；计算题数据充分；开放题说明评价依据。标注知识点和实际参考 PDF 页码，生成题称“根据教材编写”，不冒充教材原题。
4. 先自行求解核对，再交付。检查解的存在性、唯一性、公式数值与反例条件；题有问题先修题。难度来自推理要求，不通过缺条件或堆计算制造困难。
5. 默认保存为逐题卡片，答案由前端隐藏；每题提供 1–3 条渐进提示，从概念方向到关键关系再到下一步操作，第一条不泄露完整答案。解析说明关键步骤和错因，公式写一次即可，前端支持 LaTeX 源码复制。用户要求不提供答案时，省略答案与解析，也不通过提示泄露答案。
6. 作答反馈先看学生思路：指出正确部分和首个影响结论的错误，区分概念、推理与计算问题，给可继续操作的一步提示。接受等价表述与正确的不同解法，不按字符串匹配判数学题；条件不足或题目歧义先说明。用户明确要完整解答时直接提供，不强迫继续猜。
7. 补练针对有证据的错因，保持知识点并改变情境、条件或推理任务，避免只换数字。一次补练默认一道新卡片，保留原题；没有错误证据时称同知识点练习，不捏造诊断。

出题前读取 [卡片输出与交互](references/cards.md)。小提示、答题反馈直接在对话中回答，不生成或覆盖卡片；要求完整试卷或打印资料时才改用 Markdown。无需额外确认即可执行已明确的出题和反馈请求。
