# 教材内容的讲解顺序

## 明确这一节要讲成什么

先阅读目标小节，以及说明其作用的前后文。在工作记录中，用一句具体的话写出本节结束时学生应当能够解释、推导或解决的问题。例如：“利用最优性条件求出最小二乘模型的参数，并说明解的适用条件。”

根据教材前面的内容判断学生已经接触过哪些知识；将当前推理实际需要的预备知识安排在使用位置附近。用户提供学习背景时，据此调整回顾和推导的展开程度。授课时间与课次由教师自行安排。

检查教材中的每项定义、定理、证明、算法和例题，说明它在本节中的作用，以及理解它需要先掌握什么。先写出本节要解决的问题、所需知识和最终结论，再安排逐页顺序。

## 根据内容的作用确定顺序

章节与小节沿用教材层级。小节内部按理解依赖组织；用于说明定义的例子、用于解释结论的图，可以安排在首次需要它们的位置。同一小节涉及多种内容时，围绕本节问题衔接相应的讲解过程。

| 教材内容的作用 | 建议的讲解顺序 | 完成时应能回答的问题 |
| --- | --- | --- |
| 引入概念 | 可观察的对象或数学现象；需要描述的性质；正式定义及符号；满足定义的例子与边界情形；定义的用途 | 这个概念描述什么，怎样判断一个对象是否满足定义？ |
| 建立定理 | 待回答的数学问题；相关条件；完整结论；结论的直观含义；证明思路；分步证明；应用及条件的作用 | 条件怎样支持结论，怎样在具体问题中使用它？ |
| 介绍算法 | 待求解的问题；已有方法遇到的具体困难；更新思路；一次更新的实例；一般步骤；停止条件；教材给出的性质与适用范围 | 每一步计算什么，为什么这样更新，什么时候结束？ |
| 应用已有理论 | 具体问题；已知量与未知量；数学模型；选择相关理论的理由；代入与求解；结果解释；适用条件 | 前面的理论怎样帮助解决当前问题？ |
| 比较方法或总结 | 共同问题；明确的比较条件；各方法在这些条件下的行为；教材支持的结论；使用时的判断依据 | 根据什么条件选择方法，各结论适用于什么范围？ |

表中的步骤是组织依据。每一步所需页数由具体解释、公式和图示决定。正式陈述可以占据一页，完整证明通常需要若干连续页面。

## 让问题、例子和公式相互衔接

为本节选择一个具有代表性的具体问题。教材已有合适例子时，围绕该例子组织解释。补充例子的数值、维度和条件应能直接检查，其复杂程度应足以展示当前知识的作用。整份课件统一遵循主文件中的教材记号规则。补充例子使用教材中的参数向量，其各个分量直接承担具体含义。将例子推广到一般模型时，沿用这些记号说明维度和取值范围。禁止先为同一对象另设一套符号，再安排“写成教材记号”的转换步骤。

例子在首次引入抽象概念或公式的位置出现。后续推导可以反复回到同一例子，解释新增符号、执行计算和检查结果。例题题目、各阶段计算和结果通过稳定的名称与编号关联。新增例子的题目、计算和结果应具体呈现所涉及的新条件或新现象。

公式首次出现时，按以下顺序交代：

1. 当前要计算、描述或判断的对象。
2. 各符号的具体含义，以及本次求解中的已知量与未知量。
3. 公式来自哪个定义、假设、定理或计算步骤。
4. 得到公式后能够进行的计算，或能够作出的判断。

推导较长时，先说明本段要得到什么，再按推理步骤拆页。每一步写明使用的条件和结论。最终将结果代回本节问题，说明数值、参数或数学结论的含义。

定理的条件与结论完整呈现。列表或表格中并列陈述多个数学结论时，每一项、每一行写明自身所需的函数性质、定义域和约束条件；共用条件也可以在列表或表格前统一说明。总结页中的简写结论也按完整适用条件检查。某项条件决定下一步是否合法时，在该步附近说明其作用。进一步的边界情形和扩展讨论安排在相关基本结论讲清之后。

## 安排每一页及相邻页的关系

在排版前列出逐页讲解顺序，每页用一行说明：学生此前已知的内容、本页要解释的问题、本页得到的结论，以及这个结论如何引出下一页。将这些编写记录保存为工作记录或源码注释。

每页围绕一个明确的理解步骤展开。例如，“误差怎样度量”“梯度为零给出什么方程”“这个方程的解为什么最优”。标题可以使用准确的主题名称、问题或结论，具体措辞依内容决定。

相邻页之间应具有可说明的关系，例如引入定义、使用刚得到的结论、解释条件、代入例子、验证结果。需要跨页推导时，适量重述当前使用的式子和条件。

图示应参与本页解释：散点图表达数据与拟合，残差线段表达误差，曲线表达目标值随参数的变化，算法图表达更新过程。正文与图中的符号、颜色和数值保持一致，并写明读图所得的结论。

页面容纳不下一个理解步骤时，按该步骤的推理关系继续拆分，并检查拆分后的每页是否具有完整含义。重复计算的展开程度，根据它对学生理解当前结论的作用决定。

## 页面文字的取舍

每句话应对理解当前问题有具体作用：给出事实或条件、解释符号、说明推理依据、解释图形或结果。逐句检查它增加了什么信息；与标题、公式、图形或相邻正文重复的文字，按理解需要删减。

教学设计中的例子选择、页面顺序和知识依赖记录在工作记录或源码注释中。学生通过实际的问题、计算和结论感受到讲解顺序。清理正文中的编排自述，例如“贯穿例子”“本页学习目标”“接下来我们将讲解”。开头直接提出具体的学科问题；例子直接给出数据和待求量；跨页衔接直接使用上一页的结论。

当前内容的编号与名称由标题表达，上级章节路径放入 PDF 书签和源码注释。对定理、公式的引用与所用条件写在推理使用处。图例解释颜色、线型或符号所代表的对象，计算说明交代每一步的依据。

检查整页时，逐项判断文字删去后，读者是否仍能明确题意、符号、条件和推理关系。对理解没有贡献的重复定位、标签、套话和编排说明予以删除。

## 控制补充内容的位置

教材目标范围中的实质内容逐项安排。支持主要问题求解的内容形成连续讲解；较长证明或专题扩展可以在同一小节中形成有明确标题、便于选取的连续部分。

对补充推导、几何解释和额外例题，在工作记录中写出它解决的具体理解困难。引入它所需的预备知识应与本节的学习背景相符。较深入的延伸内容在基本问题得到回答后展开，并在源码注释中记录其来源和补充性质。

教材勘误先经过原页核对和数学检查。正确的公式进入正常讲解，勘误过程及原文位置记录在源码注释中。目录、教材作者、日期和制作过程等信息的展示遵循主文件中的规则。

## 最小二乘应用小节的顺序示例

本节目标：用前文的最优性条件求出线性回归参数，并解释解的条件。

| 讲解内容 | 学生理解的推进 | 适合的呈现方式 |
| --- | --- | --- |
| 数据与预测 | 给出数据和预测模型，指出需要确定的参数 | 数据表或散点图，标出观测值和预测值 |
| 拟合误差 | 解释残差及平方误差，说明怎样比较不同参数的拟合效果 | 在同一例子中计算候选参数的误差 |
| 最小二乘模型 | 将各样本的计算写成统一目标函数，解释矩阵与向量的含义 | 对照例子介绍数据矩阵、参数和响应向量 |
| 使用最优性条件 | 回顾可微无约束问题的必要条件，说明本例可以怎样使用 | 展示目标函数、梯度和驻点方程的推导 |
| 确认全局最优性 | 用海森矩阵的半正定性说明凸性，解释驻点条件的充分性 | 连接前文定理与当前矩阵的性质 |
| 求出参数 | 整理正规方程，在矩阵可逆条件下写出解 | 条件、方程、求解过程连续展开 |
| 回到同一例子 | 计算参数、预测与误差，解释得到的拟合结果 | 更新开头的图或数据表，呈现计算结果 |
| 说明条件的意义 | 解释唯一性所需条件，以及教材中的相关说明 | 使用与原例有关的条件变化；深入扩展按任务范围安排 |

这些内容可以根据解释所需的篇幅合并或拆页，实际页数以逐页讲解顺序为依据。

## 讲解质量检查

按实际页面顺序检查以下问题，并针对发现的问题调整内容：

- 本节要回答的问题是否在开头得到具体说明，结尾是否给出了对应答案？
- 每项主要内容是否能说明它在当前问题中的作用？
- 页面文字是否具体帮助理解题意、符号、条件、推理或结果，编排说明与重复文字是否已清理？
- 整份课件每一页的标题、正文、公式和图表中的记号是否与教材一致？
- 新符号的含义、预备知识和所用条件是否在使用时可见？
- 第一段实质性推导之前，学生是否已经知道正在求什么，以及为什么采用当前方法？
- 相邻页面之间是否有明确的推理或解释关系？
- 例子和图示是否实际帮助解释公式或结论，计算结果是否回到了原问题？
- 定理条件、教材主要内容和补充内容是否得到了准确安排？
- 按页讲述时，是否出现需要额外补上一整段背景才能理解当前页的地方？出现这种情况时，将必要解释补入相应位置。

内容检查完成后，再进行 LaTeX 编译和逐页视觉检查。文字、公式、图示的大小与排布应支持当前页的讲解顺序。
